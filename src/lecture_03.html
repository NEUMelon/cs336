01从第一性原理出发

第一性原理

一个 Transformer 就是一条残差流（residual stream）：x ← x + f(x) 反复做 L 次，f 交替是注意力（在 token 之间混合信息）和 MLP（在每个 token 内部加工信息）。几乎所有架构选择都可以从三个目标推出来：

  1. 可优化：梯度要能沿残差流无损地传回很深的层；各处数值不能爆炸（softmax 里的指数最危险）。
  2. 表达力：在参数量相同的前提下，让每个参数更“有用”（例如门控 GLU）。
  3. 硬件效率：FLOPs 不等于运行时间，数据搬运同样要算钱；推理时 KV cache 的大小决定吞吐。

讲者的主题：学习的最好方式是亲手实践，其次是从别人的经验里学习。2024–2025 年间仅稠密模型就发布了 19 个以上，大多只有细微的架构差别。这一课就是把它们放在一起对比：什么是共同的，什么在变，能学到什么。

03归一化

Pre-norm vs post-norm：大家唯一的共识

为什么 pre-norm 更好训练？对 pre-norm，x_L = x_0 + Σ f_l(Norm(x_l))，所以 ∂x_L/∂x_l = I + (…)：总有一条恒等路径让梯度直接从输出流回任意一层。post-norm 的每一层都要穿过一次 Norm 的雅可比矩阵，梯度在深层网络中逐层衰减或放大。

  • 文献中的解释：梯度衰减（Xiong et al., 2020）、梯度尖峰（Salazar & Nguyen, 2019）。
  • 原本宣称的好处是可以去掉 warmup；今天的主要理由是稳定性，以及大网络上能用更大的学习率。
  • 几乎所有现代 LM 都用 pre-norm（BERT 是 post-norm；OPT-350M 是个奇怪的例外）。

新做法：“双重”归一化或非残差 post-norm。如果把 Norm 放进残差流不好，那就在子层输出、加回残差流之前再做一次：x + Norm(f(Norm(x)))。Grok、Gemma 2 这样做；OLMo 2 只做子层输出的这一次（非残差 post-norm）。

LayerNorm vs RMSNorm

公式代表模型
LayerNormy = (x − μ) / √(σ² + ε) · γ + βGPT-1/2/3、OPT、GPT-J、BLOOM
RMSNormy = x / √(mean(x²) + ε) · γLLaMA 家族、PaLM、Chinchilla、T5

RMSNorm 不减均值、没有 bias β。常见解释是“更快，效果一样好”：运算更少、参数更少。

但这个解释说得通吗？矩阵乘法占了绝大部分 FLOPs，归一化的 FLOPs 微不足道。Ivanov et al. (2023) 对 BERT 的剖析给出答案：矩阵乘法占 99.8% 的 FLOPs，但只占约 61% 的运行时间；归一化只占约 0.17% 的 FLOPs，却占约 25% 的运行时间。原因是归一化是 memory-bound 的（上一课的算术强度）。

重要教训FLOPs 不等于运行时间。对 memory-bound 的操作，少读写一个张量就是实打实的提速。Narang et al. (2020) 还发现 RMSNorm 在效果上也略有提升。

去掉 bias

大多数现代 Transformer 没有 bias：FFN(x) = σ(xW₁)W₂。理由和 RMSNorm 类似（少存少搬），另外经验上对优化稳定性有好处。

门控线性单元（GLU）

GLU 改的是前馈层的“第一部分”：原来是“线性 + 激活”，现在再乘上一个逐元素的线性项作为门：

max(0, xW₁) → max(0, xW₁) ⊗ (xV)

多了一个参数矩阵 V。直觉：一路决定“是否让信息通过”，另一路提供“通过的内容”，两者相乘让网络能表达乘法交互。

为什么门控模型的 d_ff 缩小到 2/3？为了在参数量相同的前提下公平比较。

普通 FFN：两个矩阵 d×d_ff 和 d_ff×d，取 d_ff = 4d，参数 = 2 × d × 4d = 8d²。

GLU FFN：三个矩阵（W₁、V、W₂），参数 = 3 × d × d_ff。令其等于 8d²，得 d_ff = 8d/3 ≈ 2.67d。

效果：Shazeer (2020) 和 Narang et al. (2020) 都显示 GLU 变体有相当一致的提升。GLU 不是必需的（GPT-3 没用也很好），但现在已经很少看到不用的了。少数异类：Nemotron 340B 用 squared ReLU。

串行 vs 并行层

标准块是串行的：先注意力，再 MLP。GPT-J 开创了并行层：x + Attn(Norm(x)) + MLP(Norm(x))。如果实现得当，Norm 可以共享，两个输入矩阵乘法可以融合。PaLM、GPT-NeoX、Cohere Command A/R+、Falcon 2 11B 用并行层，但大多数模型仍是串行。

05位置编码与 RoPE

类型做法代表模型
正弦编码Embed(x, i) = v_x + PE_i，PE 为固定的正弦余弦原始 Transformer
绝对位置Embed(x, i) = v_x + u_i，u_i 可学习GPT-1/2/3、OPT

RoPE 的推导

第一性原理

我们希望注意力分数只依赖相对位置：找一个函数 f(x, i) 把内容 x 和位置 i 结合起来，使得

⟨f(x, i), f(y, j)⟩ = g(x, y, i − j)

已有方案都不满足：正弦编码展开内积后有 ⟨v_x, PE_j⟩ 这类交叉项，不是相对的；绝对编码显然不是；相对位置编码能做到，但不是内积形式，没法用标准注意力 kernel。

关键观察：内积在旋转下不变。如果把位置 i 的向量旋转 i 个单位角度，那么两个向量的内积只取决于它们旋转角度之差。

设 R_i 是旋转 i·θ 的矩阵，f(q, i) = R_i q。旋转矩阵是正交的，且 R_iᵀ R_j = R_{j−i}，所以

⟨R_i q, R_j k⟩ = qᵀ R_iᵀ R_j k = qᵀ R_{j−i} k

结果只依赖 j − i。高维怎么旋转？最简单的做法（受复数启发）：把 d 维向量两两配对成 d/2 个二维平面，每个平面用自己的频率旋转：

(q₂ₖ, q₂ₖ₊₁) → 旋转角度 i·θₖ，θₖ = base^(−2k/d)，base 通常为 10000

低维度的配对转得快（编码局部位置），高维度的配对转得慢（编码远距离位置）。

和正弦编码的区别：RoPE 是乘法（旋转），不是加法，所以没有交叉项。实现上它作用在每一层注意力的 q 和 k 上，而不是只在输入处加一次，这样每一层的注意力都严格满足相对位置性质。v 不旋转。Gemma 4 的一个变体只对部分维度做旋转。

07训练稳定性技巧

近年来大家非常关注训练稳定性：loss 曲线出现尖峰甚至发散，对大模型是灾难。问题最常出在 softmax 上：指数会放大数值，还可能除以接近 0 的数。模型里有两个 softmax：输出层和注意力。

输出 softmax：z-loss

输出概率 p(y) = e^{z_y} / Z，Z = Σ e^{z_k}，所以 log p(y) = z_y − log Z。

如果能让 log Z ≈ 0（Z ≈ 1），那么 log p(y) ≈ z_y，logits 本身就是良好归一化的对数概率，不会漂移到很大的数值。

做法：在损失上加一个辅助项 α · (log Z)²，PaLM 取 α = 10⁻⁴。

使用者：PaLM、Baichuan 2、DCLM、OLMo 2、OLMo 3。

注意力 softmax：QK-norm

在 q 和 k 进入点积之前，先对它们做 LayerNorm/RMSNorm。这样点积的大小有界，注意力 logits 不会爆炸。最早来自视觉和多模态模型（Dehghani 2023、Idefics、Chameleon），现在 DCLM、OLMo 2/3、Gemma 2/4、Qwen3 都在用。

Logit 软截断

用 tanh 把 logits 平滑地限制在某个最大值以内：logits ← cap · tanh(logits / cap)。能防止 logits 爆炸，但可能损失一点效果。

08注意力变体：为推理省钱

大多数模型不太改注意力头，少数例外都与推理成本有关：GQA/MQA 减少 KV 头数；稀疏或滑动窗口注意力限制注意力范围；状态空间模型等“另类”方案下一课讲。

为什么推理时注意力的算术强度很差

记号：b = batch，n = 序列长度，d = 隐藏维度，h = 头数，k = d/h 为头维度。

场景运算量内存访问算术强度
训练（整个序列一起算）bnd²bnd + bhn² + d²O((1/k + 1/(bn))⁻¹)，很高
增量生成（KV cache）bnd²bn²d + nd²O((n/d + 1/b)⁻¹)，差
MQA 增量生成bnd²bnd + bn²k + nd²O((1/d + n/(dh) + 1/b)⁻¹)

生成文本时必须一个 token 一个 token 地来，没法并行。为避免重复计算，缓存之前所有 token 的 K 和 V（KV cache），每步只算新 token。但每一步都要把整个 KV cache 从显存读一遍，n/d 这一项很难降下来：要想强度高，需要大 batch、短序列或大模型维度。

MQA 与 GQA

  • MQA（multi-query attention）：多个 query 头共享一个 K 头和一个 V 头。KV cache 缩小为原来的 1/h。Shazeer (2019) 发现困惑度有小幅损失。
  • GQA（grouped-query attention）：折中方案，把 query 头分成 g 组，每组共享一对 KV 头。g 是调节表达力与推理效率的旋钮。Ainslie et al. (2023) 显示几乎没有损失。
  • 更进一步：DeepSeek V2 的 MLA（multi-head latent attention），把 KV 压缩到低维隐空间再缓存（下一课）。

补充：KV cache 有多大？以 LLaMA 2 70B 为例：80 层，64 个 query 头，头维度 128，GQA 用 8 个 KV 头，bf16。

每个 token 的 KV cache = 2（K 和 V）× 80 层 × 8 头 × 128 × 2 字节 ≈ 0.33 MB。

如果是标准多头（64 个 KV 头），要 8 倍，约 2.6 MB/token。一个 4096 长度的请求：GQA 约 1.3 GB，MHA 约 10.7 GB。KV cache 越小，同一张卡上能并发的请求越多，decode 的 batch 就越大，算术强度也就越高。

稀疏与滑动窗口注意力

全注意力的代价随长度平方增长。稀疏或结构化注意力（Child et al., 2019）用表达力换运行时间：GPT-3、GPT-OSS、Gemma 4 都用过。滑动窗口注意力（SWA）只看最近 w 个 token，KV cache 也只需存 w 个。

当前标准做法：全局注意力和局部注意力交替。例如 Cohere Command A 每 4 层一层全注意力：长距离信息由不带位置编码（NoPE）的全注意力层负责，短距离信息由 RoPE + SWA 层负责。LLaMA 4、Gemma 3/4、OLMo 3 用 SWA + 全注意力（都带 RoPE）；Qwen 3.5 / Qwen 3 Next 把注意力和线性注意力交替。

10自测题

Q1d_model = 4096 的 SwiGLU 前馈层，想和 d_ff = 4d 的 ReLU 前馈层参数量相同，d_ff 该取多少？

8/3 × 4096 ≈ 10923。实际常取一个方便硬件的数，比如 LLaMA 7B 用 11008（256 的倍数）。

Q2RMSNorm 的 FLOPs 很少，为什么换成它还能明显提速？

归一化是 memory-bound 的：时间花在读写激活张量上，不在算术上。去掉减均值和 bias，减少了读写和参数搬运，运行时间直接下降。

Q3证明 RoPE 下注意力分数只依赖相对位置。

⟨R_i q, R_j k⟩ = qᵀ R_iᵀ R_j k。二维旋转满足 R_iᵀ = R_{−i} 且 R_a R_b = R_{a+b}，所以等于 qᵀ R_{j−i} k，只依赖 j − i。高维时各个二维平面相互独立，结论逐块成立。

Q4z-loss 惩罚的是什么？为什么这能提升稳定性？

惩罚 softmax 归一化常数的对数 log Z 偏离 0。这样 logits 被“锚定”在对数概率的尺度上，不会整体漂移到很大的值，避免指数运算溢出和 bf16 下的精度损失。

Q532 层、32 个 query 头、头维度 128 的模型，bf16，MHA 和 GQA（8 个 KV 头）下每 token 的 KV cache 分别多大？

MHA：2 × 32 × 32 × 128 × 2 = 524,288 字节 = 0.5 MB。GQA：2 × 32 × 8 × 128 × 2 = 131,072 字节 = 0.125 MB，缩小 4 倍。

Q6预训练的 LLM 基本不会过拟合，为什么还用 weight decay？

Andriushchenko et al. (2023) 发现 weight decay 的作用主要在优化动态：它和学习率调度相互作用（尤其在学习率衰减阶段），让模型最终达到更低的训练 loss，而不是提升泛化。

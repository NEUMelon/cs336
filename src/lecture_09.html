01从第一性原理出发

第一性原理

为什么要有 scaling laws？在大模型上调超参数太贵，只能在小模型上做实验。但小模型上的最优值未必适用于大模型。如果能找到一个关于规模的简单函数，就能在小规模拟合、在大规模预测。

为什么是幂律？统计学习里，估计误差通常以多项式速度下降：误差 ∝ n^{−α}。取对数后 log 误差 = −α log n + C，在双对数坐标上就是一条直线。深度学习的 scaling law 就是这种直线，只是斜率 α 比经典模型小得多。

资源怎么分配？训练计算量 C ≈ 6ND。给定 C，参数 N 和数据 D 此消彼长。如果 loss 可以写成 N 和 D 各自贡献的误差之和，就能解一个带约束的最优化问题，得到最优的 N 和 D 如何随 C 增长。

缩放并不容易：宽还是深？多少个头？什么激活函数？可以照抄已有 LM 的配置，但这些配置最初是怎么优化出来的？旧方法（令人不快）：在大模型上调超参数。新方法（也许过于乐观）：在小模型上调，再外推到大模型。

02历史与背景：数据缩放

理论学者很早就在思考“缩放”：样本复杂度、学习速率。例如在 k 个假设的有限集合中学习，或对光滑密度做生成建模，都有误差随样本数下降的界。但这些是上界，不是真正达到的 loss 值。

  • 1993 年：最早的数据缩放论文。
  • Banko & Brill (2001)：性能随数据量呈对数线性增长。
  • Kolachina et al. (2012)：数据量与下游性能之间是幂律关系。
  • Hestness et al. (2017)：最早的大规模神经网络缩放研究，在机器翻译、语言模型、语音上都观察到可预测的缩放，并提出了缩放曲线的形状假设。它非常超前：已经讨论了“涌现”、按算力缩放、速度即精度等后来的核心话题。

神经语言模型的缩放要回答三个问题：① 数据与性能：有没有简单的规律？② 数据与模型大小：该用更多数据还是更大模型？③ 超参数与性能：大模型的超参数该怎么设？

03数据缩放定律

数据缩放定律：把数据集大小 n 映射到误差的简单公式。我们期望它单调，形状像 logistic 曲线。对语言模型（Kaplan et al., 2020），测试 loss 和数据量在双对数坐标上是一条直线：“无尺度”或“幂律”。这些幂律关系在许多因素上都成立（数据、参数、算力），甚至在非标准的设定下也成立。

为什么会出现幂律

误差单调下降可以理解，但为什么是幂律？一个可能的答案：估计误差天然以多项式速度下降。

例 1：估计均值。x₁…xₙ ~ N(μ, σ²)，估计 μ̂ = Σxᵢ / n。标准推导：

E[(μ̂ − μ)²] = σ² / n ⟹ log 误差 = −log n + 2 log σ

这就是一个 scaling law，斜率 −1。更一般地，任何多项式速率 1/n^α 都是 scaling law。经典模型（回归等）用类似的论证都会得到 1/n，即双对数图上斜率为 −1 的直线。

但神经网络的实测斜率远小于 1：机器翻译、语音、语言模型的 α 大约在 0.1 到 0.3 之间。为什么？

例 2：非参数学习。神经网络能逼近任意函数。设 x₁…xₙ 在二维单位正方形内均匀分布，yᵢ = f(xᵢ) + N(0, 1)，要估计 f。把正方形切成边长 n^{−1/4} 的小格，共 √n 个格子，每格约 √n 个样本；在每格内取平均：

误差 ≈ 1/√n + 其他光滑性项

在 d 维中，同样的论证给出 误差 ≈ n^{−1/d}，也就是斜率 −1/d。

结论：灵活的“非参数”学习的 scaling law 依赖于维度。维度越高，学得越慢。

内在维度理论（Bahri et al., 2021）：scaling law 来自多项式的学习速率 1/n^α，而斜率 α 与数据的内在维度密切相关。这个解释很有吸引力，但内在维度的估计方法并不可靠，论证不算严密。

其他数据缩放问题

除了“数据量与性能”，还有“数据组成如何影响性能”：用小模型选择最优数据配比、决定是否重复数据、在质量和重复率之间权衡。

  • 分布偏移（Hashimoto, 2021）：数据组成影响的是 scaling law 的截距，不是斜率。这说明收集多样化数据很重要。
  • 用 scaling law 选配比在实践中很难：自然的想法是为每种配比建立数据 scaling law；但实证上，直接选小规模上最好的数据集往往就够了。
  • 数据重复（Muennighoff et al., 2023）：数据是有限的，重复的样本价值更低。他们定义了“有效数据量” D'，它是唯一 token 数 U_D 和重复次数 R_D 的函数：重复次数少时几乎和新数据一样好（约 4 个 epoch 以内），之后价值按指数衰减，趋于一个常数 R_D*。
  • 两条重要提醒：盲目套用时 scaling law 可能“失效”；scaling law 是下界，你总有可能做得更好。
  • 既然重复数据价值更低，数据选择应该随规模自适应：小算力时只用最高质量的数据，算力大到要重复多次时，就应该放宽过滤，纳入更多次优数据。

04用 scaling laws 做模型工程

动机：如何高效地设计巨大的 LM？LSTM 还是 Transformer？Adam 还是 SGD？模型训练更久还是做得更大？收集更多数据还是买更多 GPU？scaling laws 给出了一个简单的回答流程。

架构：Transformer vs LSTM

暴力方法：花几千万美元训练一个 LSTM 版的 GPT-3。scaling law 方法：在一系列规模上分别训练两种架构，比较两条 loss 曲线。Kaplan et al. 发现 Transformer 的曲线始终在 LSTM 下方，而且差距随规模扩大；LSTM 在长上下文位置上尤其吃亏。Tay et al. (2022) 对许多架构做了同样的跨规模比较：有些改进只在小规模有效，放大后消失。

优化器：Adam vs SGD

Hestness et al. (2017，Transformer 之前，模型是循环高速网络 RHN)：Adam 和 SGD 的 scaling 曲线平行，Adam 有一个稳定的常数倍优势。

深度与宽度

  • 1 层和 2 层差别巨大；层数再多，收益递减（参数量低于 10⁷ 时）。
  • 宽高比等超参数在很宽的范围内都接近最优，而且这个最优区间基本不随规模变化。
  • 不是所有参数都一样：嵌入层参数的行为与其他参数不同。Kaplan 用“非嵌入参数”画图才得到干净的幂律。MoE 也改变了参数的“价值”：总参数和激活参数对 loss 的贡献不同，需要专门的 MoE scaling law。

批大小：临界批大小

批大小超过某个点后收益急剧递减。临界批大小就是开始出现收益递减之前的最大批大小。更精确的定义：

选定一个目标 loss，对不同的批大小 B 训练，记录达到目标所需的步数 S 和样本数 E = B·S。实测曲线大致满足：

(S / S_min − 1)(E / E_min − 1) = 1

S_min 是批无限大时所需的最少步数，E_min 是批极小时所需的最少样本数。取 B_crit = E_min / S_min，此时步数和样本数都是各自最优值的 2 倍，两边平衡。

据称这个值接近 梯度噪声尺度 tr(Σ) / |G|²（梯度协方差的迹除以梯度范数的平方）：梯度噪声越大，越需要大批量来平均。

重要规律：目标 loss 越低，临界批大小越大。训练后期梯度信号变小、噪声相对变大，所以大模型训练常常在过程中逐步增大批大小。

学习率：muP 与规模感知的设置

如果朴素地放大模型，最优学习率会随规模变化（通常模型越宽、最优学习率越小）。需要规模感知的初始化和学习率缩放规则，例如 muP（Yang et al., 2022）：按宽度调整初始化方差和每层学习率，使最优学习率在不同宽度下保持不变，从而可以在小模型上调好直接搬到大模型（下一讲详述）。

注意：下游任务的缩放可能不可预测

到目前为止，缩放是可预测的，主要取决于参数量。但下游任务的缩放往往难预测得多（Tay et al., 2023）：两个上游 loss 相同的模型，下游表现可能差别很大。

基于 scaling law 的设计流程
  1. 训练几个小模型；
  2. 建立 scaling law（例如 Adam 与 SGD 各一条）；
  3. 根据 scaling law 的预测选择最优超参数。

令人惊讶的是，优化器、深度、架构对大模型的影响，都可以在训练之前预测。

05模型与数据的联合缩放

需要更多数据，还是更大的模型？显然，把海量数据喂给小模型是浪费。联合 scaling law 描述两者的关系：

来源形式（n = 数据量，m = 模型大小）
Rosenfeld et al. (2020)误差 = n^{−α} + m^{−β} + C
Kaplan et al. (2020)误差 = (m^{−α/β} + n^{−1})^{β}（形式略有不同）

这些形式拟合得出奇地好：Rosenfeld 在小数据、小模型上拟合指数，能准确预测其余所有点。有了它，就可以结合各自的成本，优化 n^{−α} + m^{−β} + C。

Chinchilla：计算最优的 N 和 D

Kaplan 和 Chinchilla（Hoffmann et al., 2022）都给出了数据、模型和性能的关系，但结论差很多：

N_optD_opt含义
Kaplan (2020)∝ C^0.73∝ C^0.27预算增加时主要加大模型，tokens/参数随预算下降
Chinchilla (2022)∝ C^0.5∝ C^0.5模型和数据同比例增长，约 20 tokens/参数

Chinchilla 提出了三种拟合方法：

  1. 对所有训练曲线取下包络：类似 Kaplan 的 FLOPs 图，把所有模型的训练曲线（loss vs FLOPs）画在一起，下包络是幂律，从中读出每个 FLOPs 下最优的模型。
  2. IsoFLOP：选一组 FLOPs 预算，每个预算下改变参数量（相应改变 token 数），得到一条 U 形曲线，取最低点。这些最低点构成幂律。
  3. 联合拟合：在模型大小 × 数据量的网格上训练一批模型，用最小二乘拟合联合 scaling law。

从联合 scaling law 推出最优分配。设 L(N, D) = E + A/N^α + B/D^β，约束 C = 6ND。把 D = C/(6N) 代入：

L(N) = E + A N^{−α} + B (6N/C)^{β}

对 N 求导令其为 0：αA N^{−α−1} = βB (6/C)^{β} N^{β−1}，整理得

N_opt ∝ C^{β/(α+β)}， D_opt ∝ C^{α/(α+β)}

当 α ≈ β 时，两个指数都约为 0.5：模型和数据同比例放大，tokens/参数是常数。这就是“D ≈ 20N”法则的来源。

注意这组参数的一个问题：三个预算下最优点的 tokens/参数分别约为 26、42、66，随预算增长。这是因为拟合出的 α > β。方法 1 和方法 2 给出的比例大致恒定，这个矛盾正是下面要讲的方法 3 的问题。

为什么 Kaplan 和 Chinchilla 差这么多

  • 解释一：Kaplan 没有把最后一层（输出层）参数计入参数量；在很小的算力预算下 warmup 太长；学习率衰减本身可能不那么关键，只要批大小和学习率调好。
  • 解释二：用非嵌入参数还是总参数，再加上小规模时的一些非线性，足以改变拟合出的指数。
  • 方法 3 的错误（Besiroglu et al., 2024）：有人做了“数据取证”，从论文的图中恢复出原始数据，重新拟合后得到的结果与方法 1、2 更一致（α 和 β 都约为 0.35，近似相等）。原论文的方法 3 很可能有误。

训练最优不是你真正想要的

Chinchilla 告诉你：固定训练算力下，怎样得到最好的模型。但在真实部署中，大部分算力花在推理上。推理成本与参数量成正比，所以应该“过度训练”一个更小的模型：

预期的使用量越大，前期多付训练成本就越划算。IsoFLOP 方法简单干净，已被广泛用于其他领域：扩散模型（Gulrajani et al., 2023）、MoE（Abnar et al., 2025）。

06本课要点

  • 数据缩放：log 数据量与 log 误差之间是非常线性的关系，跨领域、跨模型都成立。理论上类似泛化界（均值估计、非参数估计的例子），斜率可能与数据的内在维度有关。应用于数据收集和整理。
  • 模型缩放：对数线性关系也延伸到参数量和算力。可以用小模型来选择优化器、架构和模型大小，大幅降低训练成本。
  • 资源权衡：C = 6ND 约束下，Chinchilla 给出 N、D 约各按 C^0.5 增长，约 20 tokens/参数；考虑推理成本时应过度训练。
  • scaling 作为预测：可以判断哪些问题能靠“暴力”解决。

07自测题

Q1误差从 n = 10⁶ 到 10⁷ 下降了 20%，对应的幂律指数 α 大约是多少？

10^{−α} = 0.8 → α = −log₁₀ 0.8 ≈ 0.097。这正是神经网络 scaling law 中常见的小指数；经典统计模型 α = 1 时误差会下降 90%。

Q2用非参数学习的论证解释：为什么高维数据学得慢？

把 d 维空间切成边长 h 的小格，共 h^{−d} 个格子，每格约 n·h^d 个样本。要让每格有足够样本，h 必须随 n 很慢地缩小，误差按 n^{−1/d} 下降。维度越高，指数越小，学得越慢（维度灾难）。

Q3若 α = 0.34、β = 0.28，推导 N_opt 和 D_opt 对 C 的指数。

N_opt ∝ C^{β/(α+β)} = C^{0.28/0.62} ≈ C^{0.45}；D_opt ∝ C^{α/(α+β)} ≈ C^{0.55}。两者之和为 1，符合 C = 6ND。

Q4按 20 tokens/参数，10²⁴ FLOPs 应训练多大的模型？

C = 6N × 20N = 120N² → N = √(10²⁴/120) ≈ 9.1×10¹⁰（约 91B），D ≈ 1.8T token。

Q5为什么目标 loss 越低，临界批大小越大？

临界批大小约等于梯度噪声尺度 tr(Σ)/|G|²。训练后期，真实梯度 G 变小，而每个样本梯度的噪声并没有同比例减小，信噪比下降，需要更大的批来平均噪声，大批量才不浪费。

Q6Llama 3 70B 用了 215 tokens/参数，远离 Chinchilla 最优。这是错误吗？

不是。Chinchilla 只最小化训练算力。模型会被大量使用，推理成本与参数量成正比；用更多数据训练一个较小的模型，训练时多花一些算力，却在整个生命周期里省下大量推理算力。
